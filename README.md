# community-site

친구와 함께 만드는 커뮤니티 사이트. Next.js (App Router) + TypeScript.

## 시작하기

```bash
npm install
npm run dev      # http://localhost:3000
```

## 명령어

- `npm run dev` 개발 서버
- `npm run build` 프로덕션 빌드
- `npm run lint` 린트

## 협업 규칙

- `main`에 직접 푸시하지 않고, 브랜치를 만들어 Pull Request로 합쳐요.
- 배포는 Vercel에 이 저장소를 연결하면 `main`이 바뀔 때마다 자동으로 돼요.
